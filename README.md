# README
Total conversion mod that adds a custom GC to Counter-Strike 2. The mod uses PYTHON 3 and any failed attempts to run the mod means you need to download the official Python 3, off the Microsoft store.

# ECONOMY
Monetization does not exist so the mod uses the in-game star system adjusted to the custom GC made for the mod. Every weapon finish is able to be collected through the new economy making the mod entirely FREE-TO-PLAY.


# UPDATES
A custom launcher has been made to simplify the update installing. Roadmap is currently in the works.
