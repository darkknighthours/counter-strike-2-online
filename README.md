
# COUNTER-STRIKE 2: ONLINE
• Total conversion mod that adds a custom GC to Counter-Strike 2. The mod uses PYTHON 3 and any failed attempts to run the mod means you need to download the official Python 3, off the Microsoft store.

<img width="1919" height="1079" alt="1" src="https://github.com/user-attachments/assets/52f899fb-946c-49b7-92e2-3233c4084b8b" />




# ECONOMY
• Monetization does not exist so the mod uses the in-game star system adjusted to the custom GC made for the mod. Every weapon finish is able to be collected through the new economy making the mod entirely FREE-TO-PLAY.

# STATS
• A custom stats menu has been made to keep progress of missions and user stats, tied to your Steam profile.

# DROP SYSTEM
• Just like in real CS after match you gain XP and stars to depending on how you played the match which then you can unlock weapon finishes since it generates random drops.

# HOW TO INSTALL
• Install the .bat file (This is the current supported CS2 version)
• Run the CS2Online launcher and install the mod
• Run the mod over the launcher
• First time run might take a few minutes, Steam must be ON because it uses the Steam network to save and keep track of your items since they are tied to your ID
